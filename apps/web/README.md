# Inclusive Tourism web

React + TypeScript + Vite + Tailwind frontend for Inclusive Tourism.

## Scripts

```bash
npm install
npm run models
npm run dev
npm run test
npm run build
npm run preview
```

`npm run models` downloads YOLOv8n ONNX and ONNX Runtime WASM files. `npm run dev` starts the local app. Detection will announce that it is unavailable until the weights are present. `npm run test` runs unit tests. `npm run build` type-checks and writes `dist/`.

Ultralytics YOLO is AGPL-3.0. See `docs/MODELS.md`.
